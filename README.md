# Minimax Game-Playing Agent

## Project Overview

This project implements a Minimax-based game-playing agent for a
two-player, turn-based, zero-sum game. The agent uses adversarial search
to determine the optimal move assuming both players play optimally.

The implementation demonstrates: - Game state representation - Recursive
Minimax algorithm - Utility evaluation for terminal states - Turn
alternation between maximizing and minimizing players

## Notes

-   The Minimax algorithm explores the full game tree.
-   Performance may decrease for games with large branching factors.
-   Future improvement: Implement Alpha-Beta Pruning for optimization.
